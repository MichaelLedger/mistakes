# Shared public mistakes

Community feed for [Mistake Notebook](https://github.com/MichaelLedger/mistake-notebook).

Each **subject** lives on its own branch (`subject-math`, `subject-chinese`, …). Do not commit student work to `main`.

## Contribute (no private data)

1. Accept the in-app share protocol.
2. Export the zip from the app (erased clips + question/answer text + tags only).
3. Unzip. You should see `entry.json` and JPEG files.
4. On GitHub: **Add file → Upload files** on the matching **subject branch**, into `entries/<new-folder>/` (folder name = the `id` inside `entry.json`).
5. Open a pull request **into that same subject branch** (not `main`).

Never include names, school IDs, handwritten originals, or personal notes.
